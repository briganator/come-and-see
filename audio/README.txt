Narration slots
===============
Put the audio files in this folder with these exact names:
  ch01.mp3 … ch12.mp3        one MP3 per chapter
  come-and-see-mp3.zip       all twelve MP3s zipped
  come-and-see.m4b           the full audiobook with chapter markers
downloads.html, listen.html and each chapter page check for these files (HTTP HEAD) and switch on
their buttons and players automatically when a file is present. Nothing else needs to change.
No narration has been generated yet.
